# Week 4 – Statistics, Data Visualization & EDA

## Project
Retail Sales Analysis using Python

## Objective
Apply statistics, Matplotlib, Seaborn and Exploratory Data Analysis to a new retail dataset.

## Tasks
- Mean, Median and Mode
- Variance and Standard Deviation
- Correlation and Probability
- IQR Outlier Detection
- Five Matplotlib charts
- Four Seaborn charts
- Data inspection and cleaning
- Correlation analysis and insights
- Business recommendations

## Run
```bash
pip install pandas numpy matplotlib seaborn
python Week4_Statistics_EDA.py
```

## Files
- `retail_sales.csv` – original dataset
- `Week4_Statistics_EDA.py` – complete source code
- `before_cleaning.csv` – before cleaning
- `cleaned_retail_sales.csv` – cleaned dataset
- `final_cleaned_dataset.csv` – final dataset
- `visualizations/` – all output charts
- `Week4_Statistics_EDA_Report.pdf` – submission-ready report
